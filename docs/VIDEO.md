## Objetivo

Apresentar o sistema funcionando em ambiente local, mostrando os principais fluxos de uso e as funcionalidades entregues no projeto.

## Conteudo demonstrado

- Login no sistema com usuario de teste.
- Cadastro de produto.
- Listagem de produtos.
- Edicao de produto.
- Exclusao de produto.
- Registro de entradas e saidas de estoque.
- Historico de movimentacoes.
- Alertas e regras de estoque minimo e maximo.
- Relatorios e dashboard gerencial.
- API e testes automatizados, quando aplicavel.
