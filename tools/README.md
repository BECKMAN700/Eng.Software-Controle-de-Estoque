# Ferramentas locais

Esta pasta guarda arquivos auxiliares usados para executar tarefas locais do projeto.

## Composer

O arquivo `composer.phar` fica nesta pasta para manter a raiz do repositorio mais limpa e ainda permitir o uso do Composer mesmo em maquinas sem instalacao global.

Exemplos:

```bash
C:\xampp\php\php.exe tools\composer.phar install
C:\xampp\php\php.exe tools\composer.phar test
```
